Claude API Key

—
Used to extract fields from uploaded PO documents. Your key is stored only in this browser's localStorage and never sent anywhere except Anthropic's API directly.

Get a key at console.anthropic.com → API Keys.

Exchange Rates (per $1 USD)

—
Non-USD purchase orders (EUR, GBP, JPY) are converted to USD using these rates for all dashboard totals. Live rates are fetched automatically (daily) — enter values and press "Set manual" to lock in your own.

Import / Export

Export downloads a backup of every PO (including attached files). Import accepts that same format — use "Add to existing" to append, or "Replace all" to start fresh. Your data stays in this browser.
